# Проект по Python учебе

## В папке src находятся модули для реализации проекта

### Модуль maskes содержит:
- Функцию функия для шифрования номера карты ```get_mask_card_number```
- Функция для шифрования номера счета ```get_mask_account```
 
### Мдуль widget содержит
- Функцию является ли входная строка номером карты или номером счета ```mask_account_card```
- Функцию Преобразует строку с датой в формате "2024-03-11T02:26:18.671407" в формат "ДД.ММ.ГГГГ" ```get_date```
